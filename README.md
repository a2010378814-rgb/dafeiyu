# 桌宠 · Claude 鲸鱼娘

一只待在 Windows 桌面上的小鲸鱼娘。窗口是透明的，她浮在最上层，没事就在屏幕上溜达，撞到边会拐弯，踩空了会往下掉，鼠标凑过去她会转头看你。

身体不是一段循环视频，是几层贴图用网格变形实时拉出来的，所以能歪头、能扭头、能蹦一下。

## 怎么跑

装个 Node.js 20 或更新版本，双击 `launcher/start.bat`。

第一次要下依赖（几百 MB，泡杯茶慢慢等），下完再构建一遍页面，之后每次双击就直接开。用终端跑也一样：`npm start`。改完 `src/` 想重新打包，加个 `--rebuild`。

## 现在能做什么

- 待机时自己在桌面上走，累了会停下
- 托盘里有她的图标，右键能调大小、切成原地待机、退出
- 左键点一下她会回你

## 后面想做的

删文件的动画。现在你把文件丢进回收站，它“唰”一下就没了，太干巴。想让她跑过去抱一下、拖进小箱子，演的这出戏代替那个冷冰冰的系统提示。

还有让她能爬到桌面图标上站着——之前试过一版，够不着的时候挺滑稽，先把台阶这事做扎实再说。

## 文件在哪

贴图和模型在 `public/`，她怎么动在 `src/pet/`，窗口和托盘在 `electron/`。改完 `src/` 记得重新构建。
