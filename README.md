# 桌宠 · Claude 鲸鱼娘

一只住在 Windows 桌面上的小鲸鱼娘：透明窗口、托盘常驻、右键菜单能调大小和互动。身体是 2D 网格变形的，不是播视频。

## 启动

先装 Node.js 20 或更新版本，然后双击 `launcher/start.bat`。

第一次启动会自动装依赖（几百 MB，慢）并构建页面，之后每次直接开。想在终端里跑也行：

```
npm start
```

想强制重新构建：`npm start -- --rebuild`。

## 能做什么

- 站在桌面上，会走、会爬、会掉、会看鼠标
- 托盘常驻，右键菜单切换大小、待机模式、退出
- 点击互动

## 文件在哪

模型和贴图在 `public/`，逻辑在 `src/pet/`，窗口和托盘在 `electron/`。改完 `src` 需要重新构建（`npm start -- --rebuild`）。
